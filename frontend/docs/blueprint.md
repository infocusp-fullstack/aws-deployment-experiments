# **App Name**: Infocusp.Todo

## Core Features:

- Add Task: Allow users to input new tasks with descriptions and due dates.
- Edit Task: Enable users to modify existing task details, including descriptions, and due dates.
- Mark Task as Complete: Provide a straightforward way to mark tasks as complete.
- Calendar View: Display tasks within an integrated calendar interface.
- Task Prioritization Assistant: A tool powered by generative AI will analyze task descriptions and suggest priority levels based on deadlines and content, helping users focus on the most critical items.
- List View: A table allows the users to list, sort and page the tasks based on selected ordering and filter.
- Delete Task: Allow users to delete task.

## Style Guidelines:

- Primary color: #1f5ad0 to convey sophistication and reliability.
- Background color: Warm Gray (#F2F2F2) for a premium feel in light mode, adaptable to a darker shade in dark mode. For dark mode use #333333.
- Accent color: Light Blue (#A9BCD0) to highlight interactive elements and key information. For dark mode use #89bdd3.
- Body and headline font: 'Poppins' for a contemporary, precise feel.
- Use minimalistic Lucide icons to represent task categories and actions, ensuring clarity and aesthetic consistency.
- Employ a clean, spacious layout with a focus on content hierarchy and ease of navigation. Use of cards or containers for task groupings and calendar integration.
- Subtle animations and transitions for task updates, calendar navigation, and interactive elements to enhance user experience without being distracting.
